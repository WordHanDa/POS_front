## 1. 進入系統與桌號鎖定

為了確保餐點正確送達，系統採用「Cookie 鎖定機制」。

* **掃碼進入：** 顧客掃描桌上 QR Code 時，網址會帶有參數 `?SEAT_ID=...`。
* **自動識別：** 系統會自動解析該 ID，並向後端查詢對應的桌號名稱（如：T1, T2），顯示在介面上。
* **持久化：** 即使刷新頁面，系統仍會從 Cookie 中讀取桌號資訊，確保點餐過程不中斷。

## 2. 首頁導覽 (Home)

**功能：** 系統入口與品牌展示。

* **精選調酒 (Cocktails)：** 進入經典與原創調酒區。
* **單杯品飲 (Single Serve)：** 進入純飲類別（如琴酒、威士忌等）。
* **社群連結：** 底部設有 Instagram 連結，方便顧客追蹤社團動態。
* **警語標示：** 嚴格遵守法規，頁面底部設有「未成年請勿飲酒」及「飲酒不開車」之宣導。

---

## 3. 瀏覽酒單 (Menu)

系統將產品分為兩大類路徑：

### A. 經典與精選 (Classic / Special)

* **分區展示：** 包含氣泡類、經典款、一口酒 (Shots) 等。
* **自動載入：** 採用「捲動偵測（Intersection Observer）」技術，當您下滑到該分區時才會加載圖片與資料，節省您的手機流量。
* **快速加入：** 點擊任何品項方框，系統會顯示「+ ADD TO CART」動畫並將品項加入購物車。

### B. 單杯品飲 (Spirits)

* **類別過濾：** 提供琴酒 (GIN)、威士忌 (WHISKEY) 等詳細分類。
* **多樣規格：** 支援同款酒水不同容量（如 15ml / 30ml）的價格切換。
* **詳細描述：** 提供酒款的風味描述與背景介紹。

## 4. 購物車與點餐流程 (Cart)

點擊右下角的「購物車圖標」即可開啟清單。

### 操作步驟：

1. **調整數量：** 透過 `+` 或 `-` 按鈕修改品項數量，或點擊垃圾桶圖示移除。
2. **填寫備註：** 每個品項皆可輸入個別備註（如：去冰、要甜一點）。
3. **二次確認：** 點擊「下單」後會跳出最終確認視窗，顯示總金額與所有品項明細。
4. **正式下單：** 點擊「確認下單」後，資料會傳送至後端 POS 系統，頁面會顯示成功動畫。

## 5. 常見問題 (FAQ)

* **Q: 為什麼顯示「載入失敗」？**
* A: 系統內建自動重試機制（Retry）。若連線不穩，請點擊頁面上的「點擊重試」按鈕。


* **Q: 購物車內的紀錄會消失嗎？**
* A: 不會。除非您主動清除瀏覽器 Cookie 或下單成功，否則清單會保留 7 天。


* **Q: 如果桌號顯示錯誤怎麼辦？**
* A: 請重新掃描桌上的 QR Code，或聯繫現場工作人員協助。

## 🛠 技術規格 (給開發者)

* **前端架構：** React + React Router (HashRouter)
* **狀態管理：** React Hooks + JS-Cookie
* **API 連結：** `https://posserver-sigma.vercel.app`
* **核心組件：**
* `MenuSection.js`: 處理非同步抓取與延遲加載。
* `CartDrawer.js`: 負責購物車邏輯與下單封裝。
* `SpiritSection.js`: 處理具備規格（Variants）的品項展示。
